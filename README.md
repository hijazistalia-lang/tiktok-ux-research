# Talia Hijazi — TikTok UX Research Portfolio

This is a separate, role-targeted portfolio for UX research opportunities in e-commerce and technology.

## GitHub Pages URL

After publishing this folder in a public repository named `tiktok-ux-research`, the site URL will be:

`https://hijazistalia-lang.github.io/tiktok-ux-research/`

## Publish

1. Create a new public GitHub repository named `tiktok-ux-research`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The existing portfolio repository and URL do not need to be changed.
